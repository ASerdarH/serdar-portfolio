# Serdar Hicyilmaz — One‑page Portfolio (GitHub Pages)

This repo contains a single‑page CV/portfolio site.

## Quick start (local)
1. Open `index.html` in your browser.

## Publish for free with GitHub Pages (recommended)
1. Create a new GitHub repository (e.g. `serdar-portfolio`).
2. Upload the contents of this folder to the repo (at least `index.html`).
3. In GitHub: **Settings → Pages**
4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** (root)
5. Save. GitHub will provide a public link.

## Customize
- Replace placeholders in the **Results** section (ARR, quota, avg deal size).
- Add your LinkedIn URL under **Contact**.
- Optional: add a `favicon.ico` and an OG image.
